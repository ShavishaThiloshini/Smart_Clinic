# Smart Clinic & Doctor Appointment System
# 30-Day Implementation Plan

## 1. Project Team

| Member | Role |
|---|---|
| Shavi | Full-Stack Developer |
| Rakavi | Full-Stack Developer |

Both developers will work across frontend and backend tasks.

Responsibilities will alternate throughout the project.

---

# 2. Daily Schedule

Each development session is 1 hour 30 minutes.

| Time | Activity | Duration |
|---|---|---|
| 6:30 PM - 7:15 PM | Individual feature development | 45 minutes |
| 7:15 PM - 7:45 PM | Frontend + Backend integration / pair work | 30 minutes |
| 7:45 PM - 8:00 PM | GitHub commit, progress check & planning | 15 minutes |

---

# 3. Development Rules

Both developers should:

- Work using separate Git feature branches.
- Avoid directly changing the main branch.
- Use clear commit messages.
- Push completed work after each session where practical.
- Pull the latest shared changes before starting new features.
- Resolve merge conflicts early.
- Document frontend, backend and database changes.
- Perform a short handoff during integration periods.
